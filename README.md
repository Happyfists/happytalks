# Happy Talks

Spoken alerts for Ashita v4 (made for CatsEyeXI) by Happyfists.

Happy Talks speaks up when you get:

- a tell, or a tell from a GM
- a party or alliance invite
- a trade request
- an emote aimed at you
- someone checking you
- full bags
- a skill up
- your name said in chat

## Install

1. Copy the `happytalks` folder into `Ashita\addons\`.
2. In game, type `/addon load happytalks`.
3. To load it every time, add `/addon load happytalks` to your `Ashita\scripts\default.txt`.

## Commands

`/talks` works as a short name for every command.

| Command | What it does |
| --- | --- |
| `/happytalks` | open the window; minimise or close it and it disappears |
| `/talks on` or `/talks off` | turn all alerts on or off |
| `/talks pack <name>` | pick a voice pack, for example `/talks pack pirate` |
| `/talks test <alert>` | play one alert: tell, gm, invite, trade, emote, examined, bags, skillup or name |

Happy Talks starts hidden and keeps working in the background. In the window, click a pack to use it, press Play to hear it first, and tick each alert on or off. Settings are saved for each character.

Running chatmon, or omni's own Happy Talks? Turn one of them off, or you'll hear every alert twice.
